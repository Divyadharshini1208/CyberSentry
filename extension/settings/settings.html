About CyberSentry v1.0.0

CyberSentry – Agentic Cyber Defense Platform is a next-generation browser security extension designed to proactively identify web threats, phishing infrastructure, deceptive redirects, and malicious payload downloads.

Architecture Chrome Manifest V3
Detection Engine Deterministic Heuristic Core V1
Backend Roadmap FastAPI + AI Multi-Agent Mesh
Zero-Telemetry Privacy
  • Zero Credential Access: Passwords, form inputs, and keystrokes are never read or captured.
  • Local Computation: All heuristic analysis and risk scoring runs locally in your browser sandbox.
  • No External Tracking: Browsing history is not sent to external servers or third parties.
  • Minimum Permissions: Only APIs essential for active security defense are requested.
